# Bundled data

## `mapping.json`

The save-key de-obfuscation table, copied **unmodified** from the
[MBINCompiler](https://github.com/monkeyman192/MBINCompiler) release assets
(`v7.10.0-pre1`, published 2026-10-28, `libMBIN_version` 7.10.0.1, 1,505 key pairs).

license; the full text is in `MBINCOMPILER-LICENSE.md` next to it. The rest of this project is MIT.
Source: https://github.com/monkeyman192/MBINCompiler/releases/tag/v7.10.0-pre1

Refresh it after a game update with:

```
nms-direct-link --update-mapping            # newest stable release
nms-direct-link --update-mapping --prerelease
```

The downloaded copy is stored in your user cache directory and takes precedence over this bundled file.
You can also point `NMS_MAPPING_PATH` at any `mapping.json`.
